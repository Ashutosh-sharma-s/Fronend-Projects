# Ashutosh Sharma — Dark Portfolio Website

A responsive portfolio website inspired by the supplied visual mockup. It uses **HTML, CSS and vanilla JavaScript only** (no Python or Java in the website).

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a modern browser.

## Customize
- Replace “Ashutosh Sharma” and the example contact details in `index.html`.
- Replace the initials/photo placeholder in the hero with your own image.
- Edit the project cards and skill percentages to reflect your real work.
- Change colors and spacing in `styles.css`.

## Demo sign-up / sign-in
The login area is a front-end learning demo. Demo accounts are stored in the browser's `localStorage`; passwords are not securely protected. It does not provide real authentication and should not be used for real users or sensitive information. For production authentication, connect a trusted authentication provider or a backend with server-side validation.

## Publish online with GitHub Pages
1. Create a GitHub repository and upload `index.html`, `styles.css`, `script.js`, and `README.md` to the repository root.
2. Open **Settings → Pages**.
3. Under deployment source, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
4. Wait for GitHub Pages to publish the site and open the URL it provides.
